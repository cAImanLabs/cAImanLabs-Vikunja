# cAImanDesk

> The task manager you actually own.

cAImanDesk is a [cAImanLabs](https://github.com/cAImanLabs) fork of [Vikunja](https://vikunja.io), an open-source to-do and task management application. It carries Vikunja's full feature set plus a handful of additions layered on top (see [Features](#features) below).

> [!NOTE]
> For the development of this fork, we're using LLM-assisted coding tools throughout the codebase.

## Features

Everything upstream Vikunja offers — see [Vikunja's features page](https://vikunja.io/features/) for the full list — plus, in this fork:

* Sprint planning with story points, burndown and velocity charts
* Per-user task colors, visible as a background tint on assigned tasks
* Jira-style task types (Epic, Story, Task, Bug, Sub-task, New Feature)
* An assignee quick-filter in the task filter bar
